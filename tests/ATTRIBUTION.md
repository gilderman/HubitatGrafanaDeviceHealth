# hubitat_ci (test-time library)

These specs compile the app with [biocomp/hubitat_ci](https://github.com/biocomp/hubitat_ci)
(Artem Tokmakov, Apache 2.0). The library is cloned once per desktop, not vendored here.
The Gradle runner is [hubitat-deploy](https://github.com/gilderman/hubitat-deploy) `tests/`.
